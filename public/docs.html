Executive Summary & Platform Scope

National Land Acquisition Monitoring, GIS Cadastral Compliance & Statutory Control

BhoomiSetu (भूमिसेतु) is an enterprise GIS-native national land acquisition control, monitoring, and compliance platform designed specifically for major linear and spatial infrastructure projects across India (Highways, Railways, Industrial Corridors, Transmission Lines, and Pipelines).

Statutory Mandate

RFCTLARR Act, 2013

Full Section 4 to Section 38 legal stop-gate compliance.

National Standard

14-Digit ULPIN GIS

Bhuvan WMTS & State RoR digital land registry sync.

Master Plan Alignment

PM GatiShakti Portal

Unified multi-modal infrastructure corridor velocity tracking.

Statutory 10-Stage RFCTLARR Act 2013 Workflow

Strict SLA countdowns, statutory stop-gates, and legal compliance monitoring

Stage 1 · Section 4 SIA Notification

Social Impact Assessment (SIA) Study & Public Consultation

SIA Unit evaluates public purpose, affected families, and land extent within 6 months.

SLA: 180 Days
Stage 2 · Section 7 Expert Group Appraisal

Independent Multi-Disciplinary Expert Group Review

Evaluates whether SIA recommendation serves legitimate public purpose within 60 days.

SLA: 60 Days
Stage 3 · Section 11 Preliminary Notification

Official Gazette Notification & Land Boundary Survey

Published in Official Gazette and two local daily newspapers; bars transactions on land.

SLA: 365 Days
Stage 4 · Section 15 Hearing of Objections

60-Day Public Objection Window & CALA Inquiry

Land owners submit objections to CALA regarding area, suitability, or ownership.

SLA: 60 Days
Stage 5 · Section 19 Final Declaration

Final Acquisition Declaration & R&R Scheme Approval

Must be published within 12 months of Section 11, otherwise preliminary notice lapses.

SLA: 365 Days
Stage 6-8 · Section 21-37 Award & Compensation

CALA Valuation, 100% Solatium Award & PFMS DBT Disbursement

Calculates statutory market value multiplier (1.0x-2.0x), 100% Solatium & 12% per annum interest.

SLA: 365 Days
Stage 9-10 · Possession & Revenue Mutation

Section 38 Physical Possession & State RoR Mutation

Land handover to acquiring authority and digital updating of State Land Revenue records.

SLA: 60 Days

14-Digit ULPIN & Spatial GIS Architecture

Universal Land Parcel Identification Number (BhuAadhaar) Integration

Every land parcel in BhoomiSetu is indexed via a unique **14-digit ULPIN (Universal Land Parcel Identification Number)** derived from exact geo-coordinates of parcel vertices based on ETRS89 / WGS84 standards.

// Sample ULPIN Structure Breakdown

ULPIN: 27-045-012-008439

27: State Code (Maharashtra)
045: District Code (Pune)
012: Tehsil Code (Haveli)
008439: Parcel ID

Database Schema DDL (Neon PostgreSQL)

Relational DDL for Projects, Parcels, Workflow Stages, Notices, and Awards

-- 1. Projects Table
CREATE TABLE IF NOT EXISTS projects (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    code VARCHAR(50) UNIQUE NOT NULL,
    state VARCHAR(100) NOT NULL,
    type VARCHAR(50) NOT NULL, -- Highway, Railway, Pipeline
    total_area_ha NUMERIC(10, 2) NOT NULL,
    estimated_cost_cr NUMERIC(12, 2) NOT NULL,
    status VARCHAR(50) DEFAULT 'ACTIVE',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. Parcels Table (ULPIN Cadastral Geometry)
CREATE TABLE IF NOT EXISTS parcels (
    id SERIAL PRIMARY KEY,
    ulpin VARCHAR(20) UNIQUE NOT NULL,
    project_id INT REFERENCES projects(id),
    survey_no VARCHAR(50) NOT NULL,
    village VARCHAR(100) NOT NULL,
    owner_name VARCHAR(255) NOT NULL,
    area_sqm NUMERIC(10, 2) NOT NULL,
    category VARCHAR(50) NOT NULL, -- Private, Forest, Govt
    status VARCHAR(50) DEFAULT 'NOTIFIED',
    geojson JSONB
);

-- 3. Workflow Stages (RFCTLARR 10-Stage State Machine)
CREATE TABLE IF NOT EXISTS workflow_stages (
    id SERIAL PRIMARY KEY,
    project_id INT REFERENCES projects(id),
    stage_number INT NOT NULL, -- 1 to 10
    stage_name VARCHAR(100) NOT NULL,
    status VARCHAR(50) DEFAULT 'PENDING', -- PENDING, IN_PROGRESS, COMPLETED, DELAYED
    start_date DATE,
    due_date DATE,
    completion_date DATE,
    documents JSONB
);

Deployment & Environment Guide

Step-by-step instructions to run locally or deploy to production

// Command Line Setup

# 1. Clone & Install
git clone https://github.com/your-org/Bhoomi-Setu.git
cd Bhoomi-Setu
npm install

# 2. Configure Environment (.env.local)
DATABASE_URL="postgresql://user:password@ep-xxxx.neon.tech/neondb?sslmode=require"
GROQ_API_KEY="your_groq_api_key_here"
NEXT_PUBLIC_MOCK_MODE="true"

# 3. Database Migration
npm run migrate

# 4. Start Server
npm run dev
